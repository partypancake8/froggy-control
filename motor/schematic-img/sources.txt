Images used by ../schematic-cl57t.html (and its render ../schematic-cl57t.png). Only wires, labels,
resistor values and yellow marks are drawn by hand; every picture below is an original or a crop.
sha256 of each file is listed so a later swap is visible.

rpi-gpio-pinout.png
  Crop (x 840..1950, y 95..1095) of the official Raspberry Pi GPIO pinout diagram
  https://www.raspberrypi.com/documentation/computers/images/GPIO-Pinout-Diagram-2.png
  from https://www.raspberrypi.com/documentation/computers/raspberry-pi.html (GPIO section).
  Licence: CC BY-SA 4.0, Raspberry Pi Ltd (Raspberry Pi documentation licence).

cl57t-label-fig2.png
  CL57T(V4.0) user manual, printed page 3, Figure 2 (driver label art), rendered at 200 dpi with
  pdftoppm, cropped to the label, rotated 90 degrees so the text reads upright, and the manual's red
  callout lines removed. Source PDF (not in this repository): CL57T-V4.0-manual.pdf from
  https://www.stepperonline.co.uk/download/CL57T_V4.0.pdf
  Licence: STEPPERONLINE vendor documentation, all rights reserved; used here as a reference for a
  student project.

cl57t-s1-table.png, cl57t-microstep-table.png, cl57t-mode-table.png
  Same manual, printed pages 6 (S1 table, section 5.1) and 7 (microstep table 5.2.1, mode table
  5.2.2), 200 dpi crops. Same source and licence as above.

vendor-article-cl57t-v41-wiring.jpg
  STEPPERONLINE help article "Wiring diagram for closed loop stepper motor",
  https://help.omc-stepperonline.com/hc/s/articles/wiring-diagram-for-closed-loop-stepper-motor
  image 24e1k-cl57t-v41 (CL57T-V41 with a 24E1K motor, controller, supply), saved from that article
  on 2026-11-09. Licence: STEPPERONLINE vendor material, all rights reserved.

vendor-article-motor-table-grn-blk-red-blu.png
  Same article, the motor lead and encoder table for GRN/BLK/RED/BLU motors (image 777). Kept for the
  record; not placed in the drawing. Note its encoder table lists 8 leads (with EZ), which does not
  match the 6-core cable on our E1K. Same licence.

17hs19-2004d-e1000-leads.png
  Crops of the coil lead table and the encoder table from the 17HS19-2004D-E1000 drawing

  200 dpi, stacked. Licence: STEPPERONLINE vendor documentation, all rights reserved.
